Quiz Java: cosa stampa double r = 5 / 2?

Richiamo teorico:
- Se entrambi gli operandi sono int, / è una divisione intera: la parte decimale è scartata.
- Il risultato 2 viene poi convertito in double solo all'assegnamento: 2.0.
- Per avere 2.5 basta che un operando sia double: 5 / 2.0.
- Il tipo della variabile a sinistra non cambia il tipo dell'operazione.

English:
Java quiz: what does double r = 5 / 2 print?

Theory recap:
- If both operands are int, / is integer division: the decimal part is discarded.
- The result 2 is converted to double only on assignment: 2.0.
- To get 2.5 it is enough for one operand to be double: 5 / 2.0.
- The type of the variable on the left does not change the type of the operation.
