English:
Getters and setters in Java: controlled access to private attributes.

Theory recap:
- The getter (getName) returns the value of a private attribute.
- The setter (setName) changes it and can validate the received value.
- this.saldo is the object's attribute, saldo is the parameter.
- main only uses the public methods, never the attribute directly.
