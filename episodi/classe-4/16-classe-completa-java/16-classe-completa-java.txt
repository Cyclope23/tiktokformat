English:
The complete class in Java: private attributes, constructor, validating setter and toString.

Theory recap:
- Attributes are private: access goes through methods only.
- The constructor sets the initial values (this.nome = nome).
- The setter can reject invalid values, like a negative age.
- toString() returns the text used by println(object).
