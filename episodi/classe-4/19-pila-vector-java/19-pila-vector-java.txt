La pila (LIFO) in Java con Vector: push e pop, la classe modello e il Main che la prova.

Richiamo teorico:
- La pila è LIFO: l'ultimo che entra è il primo a uscire.
- push aggiunge in cima, pop toglie dalla cima.
- Qui la pila è una classe che usa un Vector come contenitore.
- Il Main crea la Pila e prova push e pop.

English:
The stack (LIFO) in Java with Vector: push and pop, the model class and the Main that tries it.

Theory recap:
- The stack is LIFO: the last one in is the first one out.
- push adds on top, pop removes from the top.
- Here the stack is a class using a Vector as container.
- Main creates the Pila and tries push and pop.
