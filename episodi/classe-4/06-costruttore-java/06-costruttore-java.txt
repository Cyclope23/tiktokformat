Il costruttore in Java: inizializzare un oggetto alla creazione.

Richiamo teorico:
- Il costruttore è un metodo speciale con lo stesso nome della classe e senza tipo di ritorno.
- Viene eseguito automaticamente quando si usa new.
- Può avere parametri per inizializzare gli attributi.
- Senza valori espliciti, un int di un oggetto parte da 0.

English:
The constructor in Java: initialising an object when it is created.

Theory recap:
- The constructor is a special method with the same name as the class and no return type.
- It runs automatically when new is used.
- It can take parameters to initialise the attributes.
- Without explicit values, an int field of an object starts at 0.
