English:
Copied or understood? Same C++ exercise: have the AI write the code, or write it yourself and let the AI critique it. Real test with Claude.

Theory recap:
- Copied code works in the common case, but you don't know where it breaks.
- Write the function yourself and ask the AI which inputs can break it, without rewriting it.
- Here the bug was initialising m to 0: it fails with all-negative numbers.
- Before handing in, always test edge cases (negative values, empty array).
