Variabili e costanti in C++: cosa cambia e cosa no.

Richiamo teorico:
- Una variabile è una zona di memoria con un nome e un tipo.
- Il valore di una variabile può cambiare durante il programma.
- const dichiara una costante: il compilatore vieta di modificarla.
- L'assegnamento = copia il valore a destra nella variabile a sinistra.

English:
Variables and constants in C++: what changes and what doesn't.

Theory recap:
- A variable is a named memory location with a type.
- A variable's value can change while the program runs.
- const declares a constant: the compiler forbids changing it.
- The = operator copies the value on the right into the variable on the left.
