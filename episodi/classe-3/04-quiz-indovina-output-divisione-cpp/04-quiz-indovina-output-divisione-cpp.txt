Quiz: what does this C++ code print? Answer in the comments!

Theory recap:
- a / b with two ints is integer division: 7 / 2 = 3.
- The result is converted to double only afterwards: 3.0, printed as 3.
- To get 3.5 write (double)a / b or use 7.0 / 2.
