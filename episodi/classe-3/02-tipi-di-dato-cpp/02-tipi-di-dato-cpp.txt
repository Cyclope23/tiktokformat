I 4 tipi di dato base del C++ in 30 secondi.

Richiamo teorico:
- int memorizza interi, double numeri reali, char un carattere, bool vero/falso.
- Il tipo decide quanta memoria occupa la variabile e quali operazioni sono valide.
- I caratteri si scrivono tra apici singoli: 'A'.
- cout stampa true come 1 e false come 0.

English:
The 4 basic C++ data types in 30 seconds.

Theory recap:
- int stores integers, double real numbers, char a single character, bool true/false.
- The type decides how much memory a variable uses and which operations are valid.
- Characters are written in single quotes: 'A'.
- cout prints true as 1 and false as 0.
